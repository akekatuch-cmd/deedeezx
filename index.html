รูปโปรไฟล์

เหตุผลที่อยากเรียน Full stack web development

โอยากมีสกิลที่ครอบคลุมครับ เพราะการทำได้ทั้งระบบหน้าบ้านและหลังบ้าน จะทำให้เราเข้าใจภาพรวมของระบบทั้งหมดเหมือนเห็นแผนที่ในเกม ทำให้แก้ปัญหาได้ตรงจุด ทำงานยืดหยุ่น และมีโอกาสอัปเลเวลเติบโตในสายอาชีพอย่าง Tech Lead ได้ไวขึ้น

ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้ลงมือปฏิบัติจริงกับ Framework และ Tools สมัยใหม่ที่บริษัท Tech ส่วนใหญ่เลือกใช้ครับ อยากรู้เทคนิคที่ช่วยให้การพัฒนาเว็บไซต์รวดเร็วและมีประสิทธิภาพมากขึ้น เพื่อเตรียมความพร้อมให้ตัวเองก่อนออกไปลุยงานจริง

จุดอ่อนที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา

จุดอ่อน: เอาจริงๆ คือแทบจะไม่มีพื้นฐานเลยครับ เรียกได้ว่าเริ่มจากศูนย์ เวลาเจอ Error จะแพนิกและงงมาก ไม่รู้ว่าจะต้องเริ่มแก้ปัญหาจากจุดไหนก่อน

แนวทางการพัฒนา: ต้องพยายามฝึกเขียนบ่อยๆ ให้ชินมือครับ เวลาไม่เข้าใจตรงไหนก็จะพยายามหาข้อมูล หรือเดินไปถามเพื่อนกับอาจารย์ให้เคลียร์ไปเลย จะได้ตามเนื้อหาทัน
