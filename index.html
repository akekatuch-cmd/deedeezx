รูปโปรไฟล์

เหตุผลที่อยากเรียน Full stack web development

โอกาสในการเติบโตและต่อยอดสายอาชีพ (Career Opportunities): ตลาดแรงงานสาย Tech ต้องการนักพัฒนาที่เข้าใจทั้ง Frontend และ Backend เพราะสามารถทำงานได้ยืดหยุ่น ประสานงานกับทีมต่างๆ ได้เข้าใจง่าย และมีโอกาสเติบโตไปเป็น Tech Lead หรือ Software Architect ได้รวดเร็ว

ความคาดหวังต่อวิชานี้

การใช้ Framework และเครื่องมือสมัยใหม่ (Modern Tech Stack): คาดหวังว่าจะได้ลงมือปฏิบัติจริงด้วย Framework ที่เป็นที่นิยมในอุตสาหกรรมปัจจุบัน เพื่อให้เขียนโค้ดได้เป็นระเบียบ ทำงานได้รวดเร็วขึ้น และพร้อมสำหรับการทำงานในอนาคต

จุดอ่อนที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา

จุดอ่อน: เอาจริงๆ คือแทบจะไม่มีพื้นฐานเลยครับ เรียกได้ว่าเริ่มจากศูนย์ เวลาเจอ Error จะแพนิกและงงมาก ไม่รู้ว่าจะต้องเริ่มแก้ปัญหาจากจุดไหนก่อน

แนวทางการพัฒนา: ต้องพยายามฝึกเขียนบ่อยๆ ให้ชินมือครับ เวลาไม่เข้าใจตรงไหนก็จะพยายามหาข้อมูล หรือเดินไปถามเพื่อนกับอาจารย์ให้เคลียร์ไปเลย จะได้ตามเนื้อหาทัน
